# Style reference - Momotarou Matsuri

Voice: a comic, all-ages Hudson party game in the Momotaro Densetsu world. English should read like a lively,
natural localisation of a 2000s Japanese console game: short punchy sentences, exclamation marks where the JP has
them, no archaic "thee/thou", no modern slang that will date it. Pilot: b017 (Grandpa and Grandma, the opening),
checked in-game 2026-11-01 (`work/qa/pilot_ev0`).

## Voices and tics (use as often as the JP uses its tic, no more)
| Speaker | JP markers | English devices |
|---|---|---|
| Momotaro | silent hero | narration names him: "Momotaro got...", "Momotaro examined..." |
| Grandpa (portrait, red cap) | じゃ / のォ / わし / 桃太郎や | warm old man: "Momotaro, my boy!", "eh!", "I reckon", "My, my" |
| Grandma (portrait, green scarf) | ～よ / おいで / ～ですよ | gentle: "dear", "Go have fun...", "Oh, Momotaro!" |
| Elders, hermits, gods of fortune | じゃ / ぢゃ / おるぞ / ホッホッホッ | old-man voice: "Ho ho ho! I am the God of Fortune of the North!" |
| Villagers (polite) | です / ます / 桃太郎さん | plain friendly English; keep -san |
| Kuritaro (chestnut boy) | ～クリ | ends lines with ", kuri!" ("I know where the firewood's hidden, kuri!") |
| Kakitaro (persimmon boy) | カキーッ！ | "Kakiii!" |
| Rabbits, rabbit shopkeeper | ピョン / ピョピョン | "hop!" / "Hop hop!" ("What can I do for you, hop?") |
| Tanuki | ～ポン / ポンポコ | ", pon!" / "Ponpoko!" |
| Bombee, Enon (poverty gods) | ～のねん / ボンビー | ", nonen!" at the end of a line; "Bombee!" |
